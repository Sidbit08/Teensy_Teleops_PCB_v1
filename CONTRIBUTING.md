# Contributing

This is an independently maintained hardware project by **Sidbit08**.

Before proposing a PCB change, review the schematic and layout together, explain the technical reason, and note effects on motor control, power distribution, connectors, pinout, and fabrication.

Run KiCad ERC and DRC and report any warnings. Keep component library and footprint mappings consistent. Regenerate fabrication outputs after design changes.

Do not include tokens, credentials, local backup files, or unrelated generated files.

Pull requests are subject to the maintainer's approval and the project's licensing terms.
