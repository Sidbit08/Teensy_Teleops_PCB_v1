# Validation checklist

## Confirmed design goals

- [x] Independently developed by Sidbit08
- [x] Six-wheeled rover and robotic arm
- [x] Six direct DC motor channels using 12 BTN9970LV devices
- [x] Alternate use of three dual-channel Cytron MDD10A modules
- [x] Gerber exports with PTH and NPTH drill files

## Before hardware operation

- [ ] Verify connector and Teensy pin mappings
- [ ] Check voltage levels, input polarity and power protection
- [ ] Confirm motor current ratings, thermal dissipation and driver isolation
- [ ] Document robotic-arm actuators, joints and electrical interface
- [ ] Check KiCad ERC/DRC, component placement, and fabrication files
- [ ] Manufacture and inspect the PCB
- [ ] Test power rails, motor drivers and robotic-arm actuators separately
- [ ] Validate integrated rover operation

The PCB remains at design stage; successful physical operation is not claimed.
